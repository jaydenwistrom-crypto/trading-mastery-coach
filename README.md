# Trading Mastery Coach

The Trading Mastery Coach is an installable, static study application for the public-safe material in this repository.

Current scope:

- TradePhantoms Futures Focus Part I foundations
- one worked symbol-anatomy lesson with a controlled near-miss
- active-recall questions across all confirmed Part I topics
- device-local review scheduling and mistake tracking
- mastery status based on repeated performance, not video completion
- evidence labels and links to the public source record

## Privacy boundary

The deployed app contains no paid course video, source PDF, private transcript, authenticated page capture, or private screenshot. Study progress is stored in the browser's local storage and is not uploaded or synchronized.

## Publishing

The tracked static application is in `dist/`. The GitHub Pages workflow publishes only that directory.
